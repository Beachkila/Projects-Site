How this is counted

Each project is tagged with the skills it uses. A core skill counts 2 and a supporting skill counts 1. Tile size and bar length are the sum of those weights.

Public means a repository or live page anyone can open. Working, private means it runs on my own hardware and has no public link yet. In progress means it is still being built.

Language percentages are lines of code counted in the public repositories, not counting blank lines. Languages without a percentage are used in projects that are not public yet.
