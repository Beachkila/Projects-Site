How to read the shapes

Each ribbon scores a project from 0 to 10 on four axes, left to right. A thicker ribbon means more of that axis.

Code runs from hardware to web. Art runs from hand work to digital. A project can sit on both, and it shows both ribbons.

Colors come from the scores, so projects that lean the same way look alike. The spectrum overview places each project with Code or Art scores on one warm-to-cool bar. The Spectra page shows every project side by side.
