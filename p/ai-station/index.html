    How AI Station works

    AI Station runs local language models on a Raspberry Pi 5 to produce written work in stages. A single launcher starts a chosen studio, and each studio runs a fixed set of agents in order. A marketing studio moves a brief through research, strategy, creative, copy and production; a journalism studio moves it through interviewing, research, fact-checking, writing and editing.

    Each stage is saved to its own file, so a short brief becomes a finished piece one step at a time. Models are matched to each agent by the memory they need, and everything runs offline through Ollama. Built in Python and shell, with a React dashboard and a terminal interface for the Pi.
