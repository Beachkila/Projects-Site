    IR DEV 2.0

    IR DEV develops infrared photos taken through a 530-750 nm bandpass filter. It is a single HTML page that runs in the browser, and files are decoded on the device, so nothing is uploaded.

    It opens DNG and TIFF files with Bayer, RGB or grayscale data at 8 or 16 bits. The TIFF reader is written from scratch and handles uncompressed, LZW, PackBits and Deflate files. Raw Bayer frames are binned, with each 2x2 tile becoming one RGB pixel instead of being interpolated, which halves the resolution and lowers noise.

    Editing runs in WebGL2. The captured red, green and blue bands can be routed to any output channel or mixed, with presets including Monochrome, NIR isolate, NIR - R contrast, Swap R/B and Aerochrome. White balance can be set by gray world, as shot, or by tapping a neutral patch. Tone controls cover exposure, black and white points, contrast and gamma, and there is film grain and a negative invert. A histogram shows clipping.

    The filter passband can be set in nanometers, and a measured response profile can be loaded as JSON to label the channels. Images export as JPEG or PNG, and the settings save as a JSON recipe.
